# Medical Device Documentation Template

This repository contains a structured template for medical device regulatory documentation.

## Structure

- 00-governance/
- 01-scope-and-intended-purpose/
- 02-regulatory-and-classification/
- 03-requirements/
- 04-architecture/
- 05-interfaces-and-communication/
- 06-risk-management/
- 07-usability/
- 08-ai-governance/
- 09-cybersecurity/
- 10-verification-and-validation/
- 11-localization-and-regionalization/
- 12-deployment-and-release/
- 13-post-market/
- 14-traceability/
- templates/

## Usage

Use this structure to develop regulatory documentation for medical device software, including governance, safety, risk management, and post-market compliance.
